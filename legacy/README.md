# Legacy Coursework Sources

This directory preserves selected source files from the original Data Structures coursework archive for historical comparison.

The files are kept close to their original implementation style, with text converted to UTF-8 so they are readable on GitHub. They are **not** part of the CMake build and should not be treated as the recommended implementation.

The modern C++17 code in `include/`, `src/`, `examples/`, and `tests/` is the maintained version.

Excluded from this public repository are course slides, teaching materials, executable binaries, archives, unrelated documents, and classmates' submissions.
